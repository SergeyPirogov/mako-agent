# Mako (Go)

Легка версія Mako: один бінарник ~10 МБ, ~10 МБ пам'яті. Лише диспетчер:

1. Шукає в GitLab, GitHub і Jira Cloud задачі, призначені на вас (з міткою-тригером або всі; з `allProjects` — з усіх проєктів).
2. Показує їх на дошці в браузері (`http://127.0.0.1:7777`) і в системних сповіщеннях.
3. «Віддати в Orca»: клонує репозиторій, якщо його ще немає (`~/mako/projects/<name>`), призначає задачу на вас,
   ставить статус In progress і створює workspace в Orca з агентом, задачею й інструкцією. Гілка `feature/…` для
   задач, `fix/…` для багів і GitLab Issue.
4. Коли з гілки відкрито MR/PR: коментар у задачі з посиланням, статус рев'ю (`transitions.onSuccess`), порожній опис MR
   дописується з diff гілки (`claude -p --model haiku`).
5. Після мерджу: статус Done, і задача закривається. MR закрито без мерджу → «Не виконано».
6. Завершені задачі йдуть в архів через `archiveAfterDays` (2 дні).
7. Стежить за агентом в Orca (`orca worktree ps`, кожні 10 с) — і в чаті Orca, і в терміналі: в картці видно стан
   («працює» з поточним інструментом, «чекає на вас», «закінчив», «зупинився»), останнє повідомлення агента, а для
   агента в терміналі — його екран; «Уся розмова з агентом» показує сесію Claude Code: ваші повідомлення, відповіді
   агента й рядок на кожну його дію. Коли агент чекає на вас, закінчив або зупинився — сповіщення, помаранчевий стан
   на дошці й у меню. Коли з'являється MR, Mako пише підсумок роботи з останнього повідомлення агента та змін гілки;
   з `orca.summaryComment` — і в коментар до задачі.
8. На Mac дошка й налаштування відкриваються у власному вікні Mako (системний WebKit, як у Safari): поки вікно
   відкрите, Mako є в Dock і ⌘Tab; закрите — знову лише значок у рядку меню. Посилання на MR і задачі відкриваються
   в браузері; «Відкрити в браузері» є в меню значка. На Linux і Windows — браузер.
9. Mako на iPhone: дошка ставиться на екран «Додому» як додаток (PWA) — «Віддати в Orca», «Відкласти», стан
   агентів, і ті самі сповіщення, що на Mac, пушами. Mac публікує Mako через Tailscale з HTTPS: з будь-якої мережі
   (Funnel, на iPhone нічого не треба) або лише для пристроїв вашого Tailscale. Телефон підключається один раз
   QR-кодом: Налаштування → Телефон. Без ключа пристрою дошка нічого не показує, а налаштування доступні лише на Mac.
10. Значок у рядку меню (у треї на Linux): нові задачі й ті, що в Orca, «Відкрити дошку», «Налаштування…»,
   пауза пошуку, запуск при вході в систему.
11. Налаштування (`/settings`): трекери й токени, перевірка підключення, проєкти, статуси, Orca, коментарі в задачі
   (`comments.onStart`, `comments.onReview`: за замовчуванням «Взяв задачу в роботу. Гілка {branch}. Як буде готово,
   відкрию MR.» і «Відкрив MR: {mr}»), ліміти.
   Зміни діють одразу, без перезапуску.

Вбудованого термінала, плану, автопілота й шаблонів тут немає: агент працює в Orca.

## Запуск

```sh
cd go
go build -o mako ./cmd/mako
./mako -open        # -no-tray: без значка в меню
```

Перший запуск без налаштувань відкриває сторінку налаштувань. Другий запуск не стартує ще одну копію, а відкриває дошку.
Журнал — у `.mako/mako.log`.

## Mako.app для Mac

```sh
go/packaging/mac/build-app.sh 0.3.0   # → go/dist/Mako.app і Mako-0.3.0-mac.zip
```

Універсальний бінарник (Apple Silicon + Intel), лише в рядку меню, без значка в Dock. Підпис ad-hoc, без нотаризації:
перший запуск — правий клік → «Відкрити». CI збирає його на кожен тег `v*` (job `mac-go` у `release.yml`) поруч з
Electron-версією.

Конфіг той самий, що в TypeScript-версії: `mako.config.json` і `.env` у `MAKO_HOME`, `~/.mako` або папці застосунку
(`~/Library/Application Support/Mako`). Стан — той самий `.mako/state.json`. Не запускайте обидві версії одночасно:
вони ділять порт і `state.json`.

Токени в `.env`: `GITLAB_TOKEN` (scope `api`), `GITHUB_TOKEN` (або вхід через `gh auth login`),
`JIRA_EMAIL` + `JIRA_API_TOKEN` (+ `JIRA_BASE_URL`). Для задач з Jira MR шукаються на хості `origin` репозиторію
з `GITLAB_TOKEN` або `GITHUB_TOKEN`.

## Розробка

```sh
go vet ./... && go test ./...
```

Тести ганяють диспетчер на імітації GitLab (httptest), а Orca — на фейковому скрипті.
