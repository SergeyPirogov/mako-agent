# 🦈 Mako

Mako бере ваші задачі з GitLab, GitHub і Jira, віддає їх агенту (Claude Code) і веде в трекері до мерджу:
в роботі → на рев'ю після MR → готово. Один бінарник на Go, ~10 МБ, ~10 МБ пам'яті.

> Mako — найшвидша акула. Помічає задачу першою і віддає її тому, хто її зробить.

## Як це працює

1. Mako знаходить задачі, призначені на вас, і показує їх на дошці (`http://127.0.0.1:7777`) і в сповіщеннях.
2. «Взяти в роботу» — клонує репозиторій, створює worktree з гілкою `feature/…` чи `fix/…` і запускає в ньому
   Claude Code з задачею (або віддає її в Orca).
3. Ви бачите агента в чаті на дошці: відповідаєте на питання, даєте дозволи, затверджуєте план.
4. Агент відкриває MR — Mako пише коментар у задачі й переводить її на рев'ю.
5. Після мерджу задача закривається, worktree прибирається.

## Можливості

- **Трекери:** GitLab, GitHub, Jira Cloud; створення задач прямо з дошки.
- **Агент у Mako:** чат і термінал Claude Code, кнопки дозволів, продовження сесії після перезапуску.
- **Спочатку план:** для великих задач агент спершу пише план, ви його затверджуєте.
- **MR під контролем:** CI, коментарі, конфлікти, rebase і автофікс силами агента.
- **Рецензент-агент:** другий Claude перевіряє diff перед MR.
- **Без секретів у пуші:** перед `git push` і MR агента Mako шукає в змінах токени (GitHub, GitLab, AWS, Slack,
  Anthropic…), приватні ключі, паролі з літеральними значеннями й `.env`-файли. Знайдене зупиняє пуш; на картці —
  файл, рядок і тип, кнопка «Це не секрет» пропускає рядок. Приклади на кшталт `ghp_your_token_here`, `${DB_PASSWORD}`
  чи паролі в тестах і документації не рахуються.
- **Уроки з рев'ю:** ваші правки агенту стають правилами в CLAUDE.md.
- **Телефон:** дошка як PWA з пушами через Tailscale. Підключіть телефон QR-кодом (Налаштування → Телефон), потім
  додайте Mako на екран «Додому»: iPhone — «Поділитися» ⎙ → «На екран “Додому”» (у Chrome ⎙ праворуч в адресному
  рядку, iOS 16.4+); Android — «Встановити» в Chrome. Сповіщення на iPhone — лише в Mako зі значка.
- **Статистика:** успішність, час до MR, бюджет — по проєктах і агентах.

Детально про кожну — у [docs/features.md](docs/features.md).

## Встановлення

**Mac:** завантажте `Mako-<версія>-mac.zip` з [релізів](https://github.com/SergeyPirogov/mako-agent/releases),
розпакуйте й перенесіть Mako.app у Applications. Підпис ad-hoc, тож перший запуск — правий клік → «Відкрити».

**З коду** (Go):

```sh
cd go
go build -o mako ./cmd/mako
./mako -open        # -no-tray: без значка в меню
```

Перший запуск відкриває налаштування. Повторний запуск не стартує другу копію, а відкриває дошку.

Потрібен [Claude Code](https://claude.com/claude-code) (`claude` у `PATH`); для агента в Orca — Orca.

## Налаштування

Усе налаштовується в Mako (`/settings`), зміни діють без перезапуску. Файли лежать у `MAKO_HOME`, `~/.mako` або
`~/Library/Application Support/Mako`:

| Файл | Що в ньому |
|---|---|
| `mako.config.json` | налаштування ([приклад](mako.config.example.json)) |
| `.env` | токени ([приклад](.env.example)) |
| `.mako/state.json` | стан задач |
| `.mako/mako.log` | журнал |

Токени: `GITLAB_TOKEN` (scope `api`), `GITHUB_TOKEN` (або `gh auth login`),
`JIRA_EMAIL` + `JIRA_API_TOKEN` + `JIRA_BASE_URL`. Для задач з Jira MR шукаються на хості `origin` репозиторію.

## Розробка

```sh
cd go && go vet ./... && go test ./...
```

Тести ганяють диспетчер на імітації GitLab (httptest), а Orca — на фейковому скрипті.

Збірка Mako.app (універсальний бінарник, Apple Silicon + Intel):

```sh
go/packaging/mac/build-app.sh 0.3.0   # → go/dist/Mako.app і Mako-0.3.0-mac.zip
```

Реліз: `git tag v0.3.0 && git push --tags` — CI (`release.yml`) збере Mako.app і прикріпить до релізу.
